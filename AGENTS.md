# Repository Instructions

## Project Packaging Notes

For any discussion about interview packaging, architecture positioning, LangGraph/LangChain, RAG, tools, multi-agent design, ERP Copilot scenarios, or future feature expansion, read and update:

`docs/project_packaging_workbench.md`

Keep this document as the single long-lived working note for packaging decisions. When adding new content, clearly separate:

- What is already implemented in this repository.
- What is a reasonable extension or interview packaging direction.
- What should not be overstated in an interview.

Prefer appending a dated note to the update log when the discussion introduces a new architectural idea, scenario, or interview answer.
